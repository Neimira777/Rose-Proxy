What's actually happening

      

        The button above calls /api/carelink360-session on Neimira's live backend — the same endpoint CareLink360's own system would call once they've built their integration. It checks the API key first; a missing or wrong key is rejected before anything about the member is even looked up. A correct key resolves the member's token and hands back a launch link, which opens the same companion experience a family member's private link opens — themed as Rose or Jim from that member's own profile. Nothing on this page is simulated or faked.
